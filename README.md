# Matheus Spinosi

**`Desenvolvedor FullStack`**

Sou estudante de Análise e Desenvolvimento de Sistemas na FIAP e atualmente foco meus estudos em desenvolvimento web front-end, tendo conhecimento prático em back-end também. 

Tenho experiência prática com React, JavaScript, Java, Phyton, MySQL e prototipação UI/UX utilizando o Figma. Busco constantemente transformar teoria em projetos reais, desenvolvendo aplicações para praticar responsividade, componentização, estilização, otimização e experiência do usuário.

Atualmente estou aprofundando meus conhecimentos em React + Next.JS e Java, enquanto aprimoro minha lógica de programação e boas práticas de desenvolvimento.

Busco minha primeira oportunidade de estágio na área de desenvolvimento para evoluir tecnicamente, colaborar em projetos reais e crescer profissionalmente como desenvolvedor.
